# 📄 Chat Transcritor — Roadmap e Backlog

---

# 🧭 Visão do Produto

Serviço de transcrição local robusto, capaz de:

* Processar áudio e vídeo com alta qualidade
* Gerar saídas estruturadas
* Servir como base para automação, análise e integração

---

# 🧱 FASE 1 — Core Engine (Fundação)

## 🎯 Objetivo

Garantir transcrição funcional, consistente e reutilizável

## ⚙️ Features

* Transcrição de áudio/vídeo (Whisper / faster-whisper)
* Transcrição em processamento por lote (diretório indicado)
* Suporte a múltiplos formatos (mp3, wav, mp4)
* Retorno estruturado (texto + segmentos)
* Detecção de idioma
* Salvamento em `.txt`



## 📋 Backlog

### 🔹 Setup do modelo

* Instalar e configurar faster-whisper
* Baixar modelo (base/small)
* Criar classe `TranscriptionService`

**Critério de pronto:**

* Modelo carregado e pronto para uso via código

---

### 🔹 Transcrição básica

* Implementar método `transcribe(path)`
* Iterar segmentos retornados
* Construir lista de segmentos

**Critério de pronto:**

* Arquivo de áudio → lista de segmentos com timestamps

---

### 🔹 Estrutura de retorno

* Criar padrão de resposta (dict ou dataclass)
* Incluir:

  * texto completo
  * segmentos
  * idioma

**Critério de pronto:**

* Saída padronizada e reutilizável

---

### 🔹 Persistência

* Salvar `.txt` com transcrição
* Definir pasta `data/output`

**Critério de pronto:**

* Arquivo gerado automaticamente após transcrição

---
